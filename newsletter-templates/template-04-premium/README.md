# Template 04 — Premium / Dark

Dark, premium direction (600px). Near-black green surfaces derived from the app's payment-card face colours, light serif display type, sand-300 ("gold") used sparingly for hairlines, numerals and the primary button, sage for labels. Declares `color-scheme: light dark` so dark-mode clients don't try to invert it.

**Best for:** member-only / paid-tier letters, programme launches and special editions where a premium tone is wanted.

**Note:** some clients (older Outlook for Windows, certain Android apps) may partially re-colour dark emails; test before choosing this for a broad list.

## Files

- `index.html` — standalone email HTML, English.
- `index.bg.html` — standalone email HTML, Bulgarian.
- `preview.html` — browser preview: EN + BG at desktop and mobile (375px) widths.

## Placeholders

All copy, numbers and the quote are **demo content**. Image areas are styled blocks. Links point to `#` and carry a `data-merge-tag` attribute (`{{unsubscribe_url}}`, `{{preferences_url}}`, `{{web_version_url}}`, `{{practice_url}}`, `{{program_url}}`, `{{article_url}}`, `{{app_url}}`); `{{first_name}}` is in the greeting. The postal address is a placeholder.

Design exploration only — not wired into the application.
