# Newsletter templates (design exploration)

Standalone visual exploration of six newsletter directions for DailyTrainer. **Nothing here is used by the application** — no routes, APIs, models or sending code reference this folder.

Open `index.html` in a browser for the gallery. For auto-sized preview frames, serve the folder over HTTP, e.g. `npx serve newsletter-templates` or `python -m http.server -d newsletter-templates`.

| Folder | Direction |
|---|---|
| `template-01-clean/` | Clean & Minimal |
| `template-02-editorial/` | Editorial |
| `template-03-modern/` | Modern & Friendly |
| `template-04-premium/` | Premium / Dark |
| `template-05-personal/` | Personal Letter |
| `template-06-athletic/` | Athletic |

All content is demo/placeholder content.
